🎓 Дополнительные задачи к главе IV

Геометрия 7 класс • Глава IV, §4 • Страницы 88–90 • Задачи 304–314

Привет! Мы переходим к «высшему пилотажу» главы IV. Здесь собраны задачи, которые требуют не просто знания формул, а умения выстраивать логические цепочки, делать дополнительные построения и применять метод от противного. Не бойся сложных условий — разберём каждое по шагам!

🧠 Блок 1. Настрой на решение (10–15 мин)

Прежде чем браться за дополнительные задачи, быстро проверь три ключевых факта, которые понадобятся в решениях.

Факт 1 Чему равен внешний угол треугольника?

Внешний угол треугольника равен сумме двух внутренних углов, не смежных с ним. Это главный инструмент для «перебрасывания» значений углов по цепочке равнобедренных треугольников.

Факт 2 Как сравнить две наклонные, проведённые из одной точки к прямой?

Из двух наклонных больше та, у которой больше проекция на данную прямую. Равные наклонные имеют равные проекции. Это следует из теоремы Пифагора.

Факт 3 Что говорит неравенство треугольника о точке внутри него?

Если точка M лежит внутри △ABC, то сумма расстояний от неё до двух вершин строго меньше суммы двух соответствующих сторон: MB + MC < AB + AC.

🛠 Блок 2. Решение задач (25–30 мин)

Решай в тетради, делай чертежи, а затем открывай подсказку для самопроверки.

Средний уровень Задача 304. В равнобедренном треугольнике ABC биссектрисы равных углов при основании пересекаются в точке O. Докажите, что угол BOC равен внешнему углу треугольника при вершине B.
Проверить решение
Шаг 1. Пусть △ABC равнобедренный с основанием BC, тогда ∠ABC = ∠ACB = 2α.
Шаг 2. Так как BO и CO — биссектрисы, то ∠OBC = ∠OCB = α.
Шаг 3. В △BOC сумма углов равна 180°, поэтому ∠BOC = 180° − (α + α) = 180° − 2α.
Шаг 4. Внешний угол при вершине B смежен с ∠ABC, значит, он равен 180° − ∠ABC = 180° − 2α.
Вывод: ∠BOC и внешний угол при вершине B равны 180° − 2α, что и требовалось доказать.
Средний уровень Задача 306. На рисунке AD || BE, AC = AD и BC = BE. Докажите, что угол DCE — прямой.

Рис. 1: К задаче 306. Схема построения с параллельными сторонами и равнобедренными треугольниками.

Проверить решение
Шаг 1. Точки A, C, B лежат на одной прямой, поэтому ∠ACB = 180°. Прямая AB — секущая для параллельных AD и BE, значит, ∠DAC + ∠EBC = 180° (внутренние односторонние).
Шаг 2. △ACD равнобедренный (AC = AD), поэтому ∠ACD = (180° − ∠DAC) / 2 = 90° − ∠DAC / 2.
Шаг 3. △BCE равнобедренный (BC = BE), поэтому ∠BCE = (180° − ∠EBC) / 2 = 90° − ∠EBC / 2.
Шаг 4. ∠DCE = 180° − (∠ACD + ∠BCE) = 180° − (180° − (∠DAC + ∠EBC) / 2).
Шаг 5. Подставляем ∠DAC + ∠EBC = 180°: ∠DCE = 180° − (180° − 90°) = 90°.

Вывод: Угол DCE прямой, что и требовалось доказать.

Продвинутый уровень Задача 307. На рисунке AB = AC, AP = PQ = QR = RB = BC. Найдите угол A.

Рис. 2: К задаче 307. Цепочка равнобедренных треугольников (схема).

Проверить решение
Шаг 1. Обозначим ∠A = x. В △APQ (AP = PQ) углы при основании равны: ∠AQP = x.
Шаг 2. Внешний угол △APQ при вершине P: ∠QPR = ∠A + ∠AQP = 2x.
Шаг 3. В △PQR (PQ = QR) углы при основании равны: ∠PRQ = ∠QPR = 2x.
Шаг 4. Внешний угол △AQR при вершине Q: ∠RQC = ∠A + ∠ARQ = x + 2x = 3x.
Шаг 5. В △QRB (QR = RB) углы при основании равны: ∠RBQ = ∠RQB = 3x.
Шаг 6. Внешний угол для цепочки даёт ∠ACB = ∠A + ∠RBQ = x + 3x = 4x.
Шаг 7. Так как AB = AC, то ∠ABC = ∠ACB = 4x. Сумма углов △ABC: x + 4x + 4x = 9x = 180°.
Шаг 8. Отсюда x = 20°.

Ответ: ∠A = 20°.

Базовый уровень Задача 309. Из точки A к прямой a проведены перпендикуляр AH и наклонные AM₁ и AM₂. Докажите, что: а) если HM₁ = HM₂, то AM₁ = AM₂; б) если HM₁ < HM₂, то AM₁ < AM₂.
Проверить решение
Решение а): Рассмотрим прямоугольные треугольники AHM₁ и AHM₂. У них катет AH общий, а катеты HM₁ и HM₂ равны по условию. Следовательно, △AHM₁ = △AHM₂ по двум катетам, откуда AM₁ = AM₂.
Решение б): По теореме Пифагора: AM₁² = AH² + HM₁² и AM₂² = AH² + HM₂². Так как HM₁ < HM₂, то HM₁² < HM₂². Следовательно, AM₁² < AM₂², откуда AM₁ < AM₂.

Вывод: Утверждения доказаны.

Средний уровень Задача 311. Докажите, что в треугольнике ABC медиана AM меньше полусуммы сторон AB и AC.
Проверить решение
Шаг 1. Продолжим медиану AM за точку M и отложим отрезок MD = AM.
Шаг 2. Соединим точки B и D. В △AMC и △DMB: AM = MD (по построению), CM = MB (так как AM — медиана), ∠AMC = ∠DMB (вертикальные). Следовательно, △AMC = △DMB по двум сторонам и углу между ними, откуда AC = BD.
Шаг 3. В △ABD по неравенству треугольника: AD < AB + BD.
Шаг 4. Так как AD = 2AM и BD = AC, получаем 2AM < AB + AC, откуда AM < (AB + AC) / 2.

Вывод: Утверждение доказано.

Средний уровень Задача 312. Докажите, что если точка M лежит внутри треугольника ABC, то MB + MC < AB + AC.

Рис. 3: К задаче 312. Дополнительное построение: продолжение BM до пересечения с AC в точке D.

Проверить решение
Шаг 1. Продолжим отрезок BM до пересечения со стороной AC в точке D.
Шаг 2. В △MDC по неравенству треугольника: MC < MD + DC.
Шаг 3. Прибавим MB к обеим частям: MB + MC < MB + MD + DC = BD + DC.
Шаг 4. В △ABD по неравенству треугольника: BD < AB + AD.
Шаг 5. Следовательно, MB + MC < BD + DC < AB + AD + DC = AB + AC.

Вывод: Утверждение доказано.

Базовый уровень Задача 314. Докажите методом от противного: если для трех точек A, B и C справедливо равенство AB = AC + CB, то точки A, B и C лежат на одной прямой.

Рис. 4: К задаче 314. Точка C лежит между A и B на одной прямой.

Проверить решение
Шаг 1. Предположим противное: точки A, B и C не лежат на одной прямой. Тогда они образуют треугольник ABC.
Шаг 2. По неравенству треугольника для △ABC должно выполняться строгое неравенство: AB < AC + CB.
Шаг 3. Это противоречит данному условию задачи AB = AC + CB.
Шаг 4. Следовательно, наше предположение неверно, и точки A, B и C обязаны лежать на одной прямой (причём точка C лежит между A и B).

Вывод: Утверждение доказано методом от противного.

🧠 Методическая подсказка

При решении нестандартных задач на свойства треугольника используй этот алгоритм:

  1. Сделай чертёж и отметь все равные элементы (штрихами, дугами).
  2. Ищи «цепочки»: если дано несколько равных отрезков (как в задаче 307), последовательно выражай углы через один неизвестный, используя свойство внешнего угла.
  3. Делай дополнительные построения: продолжение медианы на свою длину (задача 311) или продолжение отрезка до пересечения со стороной (задача 312) — классические приёмы, превращающие сложную фигуру в набор простых треугольников.
  4. Проверяй метод от противного: если требуется доказать коллинеарность или неравенство, предположи обратное и приди к противоречию с аксиомами или данными условия.
